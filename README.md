# UniGe SMID Projects 📊

Welcome to my UniGe SMID Projects repository!

This repository collects the main projects and some laboratories developed during my Bachelor's Degree in Mathematical Statistics & Data Management.  
Its primary goal is to showcase my work, technical skills and applied experience in data analysis, statistical modeling and programming.
I have to underline that most of the projects I am sharing in this folder were developed with the collaboration of my other colleagues, you can find their linkedin account at the end of this script.

The projects cover a wide range of topics including statistics, machine learning, databases and algorithm design, using tools such as R, Python, SAS, Java and PostgreSQL.

---

## 📘 Course Projects Overview

### 🔹 Descriptive Statistics & PCA Analysis

**Olive Oil Descriptive Analysis (R)**  
Analyzed 572 Italian olive oil samples based on fatty acid composition.

- Descriptive statistics and group comparisons by geographical area  
- Correlation analysis between fatty acids  
- Hierarchical clustering (Ward method, Euclidean distance)  

Identified strong regional patterns and key relationships between chemical components.

**Principal Component Analysis (R)**  
Applied PCA to reduce dimensionality and study the structure of the data.

- Variable standardization and component extraction  
- Selection of principal components
- Analysis of loadings and graphical representations

### 🔹 Applied Statistics 
**Sampling Project (R)**  
Estimated total legal gambling expenditure in Liguria using:
- Simple random sampling  
- Stratified sampling (proportional & Neyman allocation)  
- Bootstrap resampling for variance estimation  

Focused on identifying optimal sampling strategies and comparing estimator efficiency.

**Time Series Project (R)**  
Analyzed monthly arrivals and departures in Australia (2014–2024) using the Box-Jenkins methodology.  
Built ARIMA/SARIMA models to capture trend, seasonality and evaluated forecasts against post-COVID recovery dynamics.


### 🔹 Programming
**Java – Battleship Game Engine**  
Developed an advanced Battleship game featuring:
- Custom-shaped ships and mines  
- Player vs computer logic  
- Hit detection and game rules  
- Integration with a graphical interface  

**Python – Convex Hull Algorithm**  
Implemented an algorithm to compute the upper convex hull of planar points in linear time.  
Used stack-based techniques and geometric tests, ensuring **O(n)** worst-case complexity.

### 🔹 Base di Dati

**UNIGE Social Sport (PostgreSQL)**  
Designed and implemented a relational database system including:
- ER modeling and schema design  
- Constraints, triggers, and views  
- Data population scripts and analytical queries  

Ensured normalization (BCNF), data integrity and enforcement of business rules.


### 🔹 Statistical Programming

**US Cars Dataset Analysis (1979)**  
Performed data analysis using SAS:
- Data cleaning and unit conversion  
- Correlation analysis and visualization (boxplots, scatterplots)  
- Comparative analysis across US, European and Japanese cars  

Identified patterns in price, fuel efficiency and regional manufacturing differences.


### 🔹 Machine Learning

This folder contains the practical materials, Jupyter Notebooks and written lab reports developed during the **Machine Learning** course. 

The repository covers fundamental concepts and algorithms of Machine Learning, ranging from synthetic data generation to supervised and unsupervised learning techniques. For each laboratory session, both the implementation code (.ipynb) and detailed written reports in Italian (.pdf) are provided.

---

### Topics Covered

* **Lab 0 — Data Generation:** Synthetic dataset creation and data preparation workflows.
* **Lab 1 — K-Nearest Neighbors (k-NN):** Implementation and analysis of $k$-NN algorithms, including advanced variants.
* **Lab 2 — Regularized Least Squares (RLS):** Linear regression models and regularization techniques.
* **Lab 3 — Logistic Regression:** Classification modeling, probabilistic approaches, and evaluation metrics.
* **Lab 4 — Kernel Regularized Least Squares (KRLS):** Non-linear regression using kernel methods and extensions.
* **Lab 5 — Neural Networks (NN):** Multi-layer perceptrons, architecture building and image classification.
* **Lab 6 — Orthogonal Matching Pursuit (OMP):** Sparse representations, feature selection and dictionary learning techniques.
* **Lab 7 — K-Means Clustering:** Unsupervised learning

---

For each laboratory (`Lab0` to `Lab7`), you will find:
* **`*.ipynb`**: Jupyter Notebooks containing code implementations, experiments, and visual outputs.
* **`*.pdf`**: Detailed reports written in Italian explaining the theoretical background, implementation details, parameter tuning and discussion of experimental results.

### 🔹 Biostatistics

**Treatment Effect on PSA Levels (SAS)**  
Analyzed longitudinal data to evaluate treatment effects on PSA levels:
- Multiple linear regression on log-scale  
- Control for confounders (age, baseline PSA, seasonality)  
- Model diagnostics and assumption checks  

Estimated relative changes and interpreted clinical impact.


### 🔹 Linear Models

**Generalized Linear Models (SAS)**  
Modeled contraceptive use using binomial regression:
- Link functions: logit, probit, clog-log  
- Model comparison via AIC, BIC, deviance  

**Multivariate Models & Repeated Measures (SAS)**  
Analyzed heart rate response under different diets and exercise types:
- Multivariate linear models  
- Repeated measures ANOVA  
- Hypothesis testing using Wilks, Pillai, Hotelling-Lawley, Roy statistics
